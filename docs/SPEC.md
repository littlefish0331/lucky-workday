# 準時下班宮 V1 規格（已與使用者確認，2026-11-20）

> 改動任何數字或流程之前，先問使用者。

## 1. 一句話

輸入名字、選一個最痛的事、按手印立契約、搖籤、擲筊，神明賜你一個職場法號和一支籤。存成圖，貼到 Threads。

## 2. 流程

```
首頁（一句話、一顆大鈕）
 ① 報上名來      輸入名字（回訪者自動帶入，可改）
 ② 最痛的事      6 顆選項（辦公室／工程／業務接案／服務輪班／通勤／錢，各一），可「換一批」，點了就往下
 ③ 按手印立契約  長按紅印泥約 1 秒，震動或震屏，隨機手印
 ④ 搖籤筒        拖曳搖晃，3 秒內出籤（不用手機感應器，不跳權限視窗）
 ⑤ 擲筊          一鍵擲，最多 2 擲
 ⑥ 揭曉          蓋印、賜法號、籤卡
    ├ 吉側 ────────────────────────────▶ ⑦
    └ 凶側 → 敲木魚積陰德 → 重抽一次
             ├ 抽到吉 ──▶ ⑦（卡片註記「原抽 X・敲 N 下・改判」）
             └ 仍凶 → [認命] 或 [再敲木魚化解] ──▶ ⑦（認命：保留原籤；化解：蓋「已化解」章並附化解建議）
 ⑦ 存圖／發 Threads／揪同事合籤／籤冊
回訪者：進廟 → 搖籤筒 → 擲筊 → 揭曉（約 15 秒）
```

「放棄」＝認命，保留原籤。「化解」＝再敲一輪木魚，蓋「已化解」章。

## 3. 抽籤規則

- **同名同日同籤**：亂數種子 = 名字（NFKC、去空白）＋台北日期＋第幾次抽。重新整理不會變。
- 名字只存本機。
- 吉凶等級出現率（先抽等級，再從該等級挑籤）：

| 等級 | 出現率 | 籤數 | | 等級 | 出現率 | 籤數 |
|---|---:|---:|---|---|---:|---:|
| 上上籤 | 6% | 40 | | 小凶 | 18% | 75 |
| 大吉 | 12% | 60 | | 凶 | 14% | 75 |
| 吉 | 17% | 75 | | 大凶 | 8% | 55 |
| 小吉 | 20% | 75 | | 下下籤 | 5% | 45 |
| **好運** | **55%** | **250** | | **壞運** | **45%** | **250** |

- 挑籤權重：痛點相同 ×4、主題相同 ×2、其他 ×1。時令籤只在窗口期內出現。重抽排除上一支。
- 法號：名字的最後一個字（非中文取首字母大寫）＋「・」＋依等級挑的稱號。

## 4. 擲筊（機率調整成不卡關）

| 結果 | 機率 | 後續 |
|---|---:|---|
| 聖筊 | 75% | 直接揭曉 |
| 笑筊 | 22% | 神明笑你，再擲一次，**第二擲保證聖筊** |
| 陰筊 | 3% | 隱藏款特別籤「神明已讀不回」，不用重擲 |

## 5. 木魚（次數隨機，玩家看不到目標）

| 情境 | 要敲幾下 |
|---|---|
| 抽到小凶，重抽 | 8–14 |
| 抽到凶，重抽 | 12–20 |
| 抽到大凶，重抽 | 16–26 |
| 抽到下下籤，重抽 | 20–32 |
| 第二次仍凶，化解 | 24–36 |

- 每敲一下冒一句碎念（「+1 陰德：昨天沒有已讀不回」）。神像表情在 30%、60%、90% 改變。偶爾 +5 暴擊。
- 提供「我手痠了」自動敲選項。
- 所有數字放在單一設定檔。

## 6. 手印

預先做好多款圖，隨機出現並隨機旋轉、縮放：
指印 4 款 35%、掌印 2 款 25%、**貓掌 3 款 20%、狗掌 3 款 20%**。貓掌或狗掌出現時，籤卡上加一行「由 🐱／🐶 代為簽收」。

## 7. 籤詩（500 支）

- 6 個主題：office 辦公室、engineer 工程、sales 業務接案、service 服務輪班、commute 通勤、money 錢與年終。
- 6 種籤型輪流：quote 台詞、notice 系統通知、dialogue 對話、checklist 運勢清單、murmur 神明碎念、yiji 宜忌。
- 約 60 支時令籤（尾牙、年終、跨年、春節、開工、發薪日），可含無政治性的時事梗。
- **每張卡都有的共同元素**：籤號、等級、籤眼（一句最醒目的話）、名字＋法號、日期、手印、今日煩惱標籤、網址。
- 格式、字數上限、禁用句型見 `content/WRITING-GUIDE.md`。

## 8. 分享

- 一鍵存圖（1080×1920）。順序：系統分享選單 → 下載 → 長按存圖。
- 「去 Threads 發文」按鈕：`https://www.threads.com/intent/post?text=…&url=…`。官方只支援文字與連結，不含圖片。
- 提供 2–3 種分享文案，結尾邀請留言互動。
- 「揪同事合籤」：狀態編進連結，不需伺服器（V1.1）。

## 9. 計數（Redis）

```
瀏覽器 ─(publishable key)→ Supabase Edge Function ─(secret)→ Upstash Redis
```

計：今日第 N 位求籤者、每支籤被抽次數、吉凶分布、木魚累計下數。計數壞掉時遊戲照常。

## 10. 範圍

**V1 不做**：造籤與投稿（V2：只收一句話約 40 字，審閱後加入籤筒）、帳號、合籤（V1.1）、每支籤獨立預覽圖（V1.1）。
**聖誕版**：引擎與內容分離，之後換內容包即可。
